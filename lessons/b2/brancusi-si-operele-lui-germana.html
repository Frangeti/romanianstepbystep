Lernziele

Nach dieser Lektion können Sie über Kunst, Stil und Bedeutung von Brâncuși auf Rumänisch sprechen, zentrale Ideen in einem Text erfassen und Vergleiche sowie Superlative korrekt nutzen.

Wissen, welche Werke Brâncuși als ikonisch betrachtet und warum sie stilbildend waren.
Wortschatz zu Kunst, Form, Material und Bedeutung erweitern.
Vergleiche und Superlative in argumentativen und beschreibenden Sätzen anwenden.
Eine kurze persönliche Stellungnahme zu Kunst und Schönheit formulieren.

1. Einstieg · Ce simți la prima vedere?

Vor dem Lesen

  1. Ce te atrage în prima vedere la o sculptură abstractă?
  2. Este importantă forma sau conținutul?
  3. Poți spune că o operă este „mai frumoasă” decât alta?
  4. Care este diferența dintre artistic și decorativ?
Redemittel: Din punctul meu de vedere… / Cea mai importantă caracteristică este… / O operă pare mai expresivă decât alta, deoarece… / Arta modernă este mai provocatoare decât arta tradițională.

3. Lesen · Brâncuși și sculpturile sale

Brâncuși a fost un sculptor important. El nu a vrut să copieze realitatea exact. El a vrut să arate esența lucrurilor. De aceea, formele sale sunt simple, dar puternice.

O sculptură a lui Brâncuși poate părea simplă la prima vedere. Dar este clară și expresivă. O linie sau o formă poate spune foarte mult. Asta este ideea lui: mai puține detalii, dar mai mult sens.

Maiastra este o lucrare cunoscută. Este mai austeră decât multe sculpturi tradiționale. Totuși, transmite putere și calm. Este una dintre cele mai importante opere ale sale.

Coloana Infinitului este una dintre cele mai cunoscute opere ale lui Brâncuși. Ea face parte din Ansamblul Monumental de la Târgu Jiu, dedicat eroilor din Primul Război Mondial. Coloana este formată din module care se repetă și pare că urcă spre cer. Nu este importantă numai prin înălțime, ci și prin ideea de continuitate și eternitate.

Brâncuși a folosit marmură, piatră și bronz. El a făcut din material un mod de a transmite emoții. În concluzie, Brâncuși este important pentru că a făcut arta mai simplă, dar mai profundă.

4. Fixare · Întrebări simple

A. Alege răspunsul corect.

1. Brâncuși a vrut să:

2. Maiastra este:

3. Coloana Infinitului este importantă pentru că:

B. Răspunde cu adevărat / fals.

1. Brâncuși a folosit multe detalii în operele sale.

2. Sculpturile lui Brâncuși sunt mai simple, dar mai puternice.

3. Maiastra transmite doar veselie.

4. Brâncuși folosea materiale ca marmura și bronzul.

C. Completează propozițiile.

1. Brâncuși a vrut să arate _______ lucrurilor.

2. O sculptură poate fi ___ simplă, dar ___ puternică.

3. Coloana Infinitului este ___ importantă decât multe clădiri.

5. Grammatik · Comparativ și superlativ

Aici sunt doar regulile de bază. În B2 poți folosi aceste forme ușor.

Tip Formă Exemplu
Comparativ mai ... decât Forma este mai simplă decât în alte opere.
La fel de ... ca la fel de ... ca Opera este la fel de puternică ca cea anterioară.
Superlativ cel mai / cea mai Aceasta este cea mai importantă lucrare.
Foarte foarte / extrem de Este foarte simplă, dar foarte bună.

6. Exerciții de fixare

A. Alege varianta corectă.

1. Sculptura este ___ simplă decât opera tradițională.

2. Aceasta este ___ importantă lucrare a artistului.

3. Opera este ___ clară ca și cea veche.

4. Brâncuși a făcut lucruri ___ puternice.

B. Pune cuvântul potrivit.

1. Forma este ___ clară decât în alte lucrări.

2. Aceasta este ___ expresivă operă.

3. Opera este ___ de clară ca cealaltă.

4. Sculptura este ___ frumoasă.

C. Traduceți în română.
  1. Die Form ist einfacher als bei anderen Werken.
  2. Das ist die wichtigste Arbeit des Künstlers.
  3. Die Skulptur ist genauso stark wie die ältere.
  4. Die Idee ist sehr klar.
1. Forma este mai simplă decât la alte lucrări. 2. Aceasta este cea mai importantă lucrare a artistului. 3. Sculptura este la fel de puternică ca cea veche. 4. Ideea este foarte clară.
D. Găsește antonimul / răspunsul corect.

1. simplu = ______

2. puternic = ______

3. important = ______

4. frumos = ______

E. Completează propozițiile cu un comparativ bun.

1. Maiastra este _______ decât multe sculpturi tradiționale.

2. Forma lui Brâncuși este _______ decât forma realistă.

3. Aceasta este _______ lucrare a sa.

4. Opera este _______ puternică.

7. Sprechen · O operă, o interpretare

Privește imaginile și comentează: descrie forma, materialul și impresia ta. Nu există un singur răspuns corect.
  1. Care operă are forma cea mai simplă?
  2. Ce operă pare mai înaltă sau mai dinamică?
  3. Ce material crezi că a fost folosit?
  4. Ce emoție transmite fiecare operă?
  5. Care operă este mai expresivă decât celelalte? De ce?
  6. Folosește în răspuns cel puțin două comparații.

Rol A

Spuneți ce vă atrage la o operă de artă modernă: liniile, spațiul, materialul sau emoția. Comparați cu o operă clasică.

Rol B

Argumentați de ce o formă simplă poate fi mai puternică decât o formă realistă. Folosiți comparații și superlative.

Redemittel

Diskussion:

„Este mai interesantă o operă simplă, dar puternică, decât una complexă, dar banală?” Formulați două argumente, un contraargument și o concluzie.

8. Schreiben · O analiză scurtă

Sarcină B2 (180–220 de cuvinte): Scrieți un scurt text despre o operă a lui Brâncuși pe care o considerați importantă. Explicați ce face lucrarea specială, ce sentiment transmite și de ce este mai puternică decât o operă tradițională. Folosiți cel puțin 6 cuvinte din vocabular și 4 structuri cu comparație sau superlativ.

0 / 180–220 cuvinte

Conținut
opera + explicația
Structură
introducere, analiză, concluzie
Limbă
comparative + vocabular
Registru
formal, clar și argumentat
